Много запросов про каждый инструмент проходили сначала через Google, тот же Gemini (1.5 pro)\

В конечном итоге решил использовать два разных инструмента для back/front.

## Выбранный AI-setup

 * OpenIDE + kilo Code - backend разработка (anthropic/claude-sonnet-4.5.)
 * VS Code + kilo Code - frontend разработка
 * ИИ режим Google (Gemini) - для проектирования плана работ

## Рассмотренные альтернативы

 * Cursor для front разработки, но он недоступен в РФ
 * Cline как плагин ИИ агента, но kilo Code вырос из этого проекта и сейчас уже выше по возможностям
 * GigaIDE + gigaCode для backend разработки, но решил оставить на потом
 * локальная модель, но отказался из-за необходимости держать включенным дополнительную машину.
